## 🎯 **About The Project**

**Personal Finance Tracker CLI** is a high-performance, fully asynchronous console application designed for tracking daily incomes, expenses, category budgets, and financial analytics. Built with **Python 3.10+**, **`asyncpg`**, and **PostgreSQL**, it uses non-blocking database operations with Connection Pooling to handle real-time balance calculations safely and quickly.

| **`tabulate`** | CLI table rendering for clean database record outputs |
